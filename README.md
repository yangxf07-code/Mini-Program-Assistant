# 兴趣卡官方助手

基于 Figma「小程序测试」设计的移动端 Web App。直接用浏览器打开 index.html 即可体验，图片和图标随项目提供。

## 体验路径

- 首页侧边栏 → 通知消息 → 全部或小程序 → 兴趣卡消息。
- 首页侧边栏 → 常用小程序 → 兴趣卡官方助手 → 发现或消息。
- 发现 → 创作指南 → 活动订阅，或从榜单进入兴趣卡广场、作者页。
- 消息支持名称与类型组合筛选、时间升降序、详情、历史和删除。点击卡片右侧的更多按钮打开操作菜单。按 Esc 或浏览器返回可回到上一层。

项目使用原稿示例数据。删除记录和订阅选择保存在当前浏览器，不会触发真实平台消息。

## 开发

使用 Node.js 22 或更高版本。在仓库根目录执行：

```sh
npm ci
npm run build
npm start
```

打开 http://127.0.0.1:4173 。已提交的 index.html 可直接预览，或与 assets 目录一起部署至静态主机。

src/views 包含按界面拆分的 React 视图。src/app.js 处理页面导航、筛选与状态。src/styles.css 定义布局适配，scripts/build.mjs 将视图和样式编译为可离线使用的页面。

## 发现页上滑吸顶

在「发现」页向上滚动榜单，创作指南随内容滚出。「用户最爱 / 近期热门」到达顶部导航下方后固定，榜单继续滚动。吸顶时可直接切换榜单，当前位置保持不变。向下滚回页首可再次看到指南。对应 Figma 画板「发现tab-上滑吸顶」（80:3926）。
